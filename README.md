# 🥊 Бокс · Комбо

Веб-приложение для тренировки бокса: показывает комбинации ударов анимацией боксёра и называет их голосом.

## Возможности

- **Анимация**: фигура боксёра выполняет каждый удар (прямые, боковые, апперкоты, в голову и в корпус) и защиту (уклоны, нырки, блок, шаг назад). Передняя рука — синяя, задняя — красная.
- **Озвучка** на русском: названиями («Джеб, кросс, левый боковой») или цифрами («1, 2, 3»).
- **Тренировка по раундам**: таймер, гонг, сигнал за 10 секунд до конца раунда, отдых между раундами.
- **Уровни**: новичок (2–3 удара), средний (3–4 + защита и корпус), профи (до 6 ударов).
- **Стойка**: правша или левша — стороны ударов меняются автоматически.
- **Библиотека** классических комбинаций: нажми на любую, чтобы увидеть и услышать.
- Экран не гаснет во время тренировки, настройки сохраняются на устройстве.

## Нумерация ударов (для правши)

| № | Удар |
|---|------|
| 1 | Джеб (прямой левой) |
| 2 | Кросс (прямой правой) |
| 3 | Левый боковой |
| 4 | Правый боковой |
| 5 | Левый апперкот |
| 6 | Правый апперкот |

«к» после цифры — удар в корпус.

## Установка на iPhone (экран «Домой»)

1. Открой сайт приложения в **Safari**.
2. Нажми **«Поделиться»** (квадрат со стрелкой вверх).
3. Выбери **«На экран Домой»** → **«Добавить»**.

Появится иконка «Бокс Комбо». Приложение запускается на весь экран и работает без интернета.
На Android: Chrome → меню ⋮ → «Установить приложение».

## Запуск

Это один файл `index.html` без зависимостей — просто открой его в браузере (на телефоне или компьютере).

Чтобы пользоваться с телефона по ссылке, включи GitHub Pages: **Settings → Pages → Deploy from a branch**, выбери ветку и папку `/ (root)`.
