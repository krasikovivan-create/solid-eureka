# 🥊 Бокс · Комбо

Веб-приложение для тренировки бокса: показывает комбинации ударов анимацией боксёра и называет их голосом.

## Возможности

- **Мой боксёр**: фигура в полный рост; в настройках можно загрузить своё фото (лицо появится у боксёра) и выбрать цвета одежды. Фото хранится только на устройстве и никуда не отправляется.
- **Анимация**: фигура боксёра выполняет каждый удар (прямые, боковые, апперкоты, в голову и в корпус) и защиту (уклоны, нырки, блок, шаг назад). Передняя рука — синяя, задняя — красная.
- **Озвучка** на русском: названиями («Джеб, кросс, левый боковой») или цифрами («1, 2, 3»).
- **Тренировка по раундам**: таймер, гонг, сигнал за 10 секунд до конца раунда, отдых между раундами.
- **Уровни**: новичок (2–3 удара), средний (3–4 + защита и корпус), профи (до 6 ударов).
- **Стойка**: правша или левша — стороны ударов меняются автоматически.
- **Библиотека** классических комбинаций: нажми на любую, чтобы увидеть и услышать.
- **Без повторов**: случайные комбинации никогда не повторяются — приложение помнит всё, что уже показывало (счётчик и сброс — в настройках).
- **Отработка**: отметь галочками нужные комбинации (классические или свои) — в режиме «Отработка» будут только они, в случайном порядке.
- **Конструктор**: собери свою комбинацию из ударов, защиты, работы ног и финтов.
- **Раздел «Ломаченко»** — упражнения в духе его подготовки (не официальная программа):
  - *Защита, ответ и выход* — боксёр на экране становится соперником и бьёт в тебя удар или серию; защищаешься от каждого удара, отвечаешь своей серией и уходишь с линии атаки. Подсказка ответа — до атаки, после или без неё;
  - *Углы и пивоты* — после каждой серии уход с линии атаки;
  - *Финты* — серия начинается с финта джебом, плечом, шагом или вниз;
  - *Реакция на цвет* — экран вспыхивает цветом, каждый цвет — своё действие;
  - *Голова под нагрузкой* — между сериями задачи на счёт и память;
  - *Вне ринга* — таймер для жонглирования, мяча на резинке, стойки на руках, скакалки.
- Экран не гаснет во время тренировки, настройки сохраняются на устройстве.

## Нумерация ударов (для правши)

| № | Удар |
|---|------|
| 1 | Джеб (прямой левой) |
| 2 | Кросс (прямой правой) |
| 3 | Левый боковой |
| 4 | Правый боковой |
| 5 | Левый апперкот |
| 6 | Правый апперкот |

«к» после цифры — удар в корпус.

## Установка на iPhone (экран «Домой»)

1. Открой сайт приложения в **Safari**.
2. Нажми **«Поделиться»** (квадрат со стрелкой вверх).
3. Выбери **«На экран Домой»** → **«Добавить»**.

Появится иконка «Бокс Комбо». Приложение запускается на весь экран и работает без интернета.
На Android: Chrome → меню ⋮ → «Установить приложение».

## Запуск

Это один файл `index.html` без зависимостей — просто открой его в браузере (на телефоне или компьютере).

Чтобы пользоваться с телефона по ссылке, включи GitHub Pages: **Settings → Pages → Deploy from a branch**, выбери ветку и папку `/ (root)`.

# 💬 Связь (папка `chat/`)

Мессенджер на React + TypeScript, который работает и без интернета: сообщения хранятся в localStorage,
фото и видео — в IndexedDB, неотправленное уходит само при появлении связи. Друзья по номеру и из контактов
телефона, группы, настоящие аудио- и видеозвонки (WebRTC) через свой сервер `chat/server` (разворачивается
на Render по `render.yaml`), плюс демо-контакты для знакомства.
Открывается по адресу `https://<пользователь>.github.io/solid-eureka/chat/`.

Подробности — в [chat/README.md](chat/README.md).

# 👗 Бот интернет-магазина одежды (папка `shop-bot/`)

Telegram-бот магазина на Python (aiogram 3, SQLAlchemy, PostgreSQL): каталог с фильтрами, корзина и промокоды,
оформление заказа с доставкой и оплатой (ЮKassa / при получении), отслеживание заказов, рассылки, рефералы,
админ-панель внутри Telegram и ИИ-стилист на Claude API, который собирает образы только из товаров каталога.
Запускается локально, в Docker или на Railway/Render.

Подробности и пошаговый запуск — в [shop-bot/README.md](shop-bot/README.md).
