# 🎓 ИИ Академия

Игра-учебник: как пользоваться нейросетями — ChatGPT, Claude, Gemini, Microsoft Copilot, Perplexity,
DeepSeek, GigaChat, Алиса, Midjourney, Suno, GitHub Copilot — и свежие новости о каждой из них.

## Для кого

При первом запуске выбирается возраст — от него зависят тексты, список нейросетей и вопросы:

| Группа | Что меняется |
|---|---|
| 🧒 Дети 7–10 | Упрощённые объяснения, только подходящие по возрасту сервисы, акцент на «вместе со взрослыми» |
| 🧑‍🎓 Подростки 11–17 | Полные уроки, возрастные ограничения сервисов, честная учёба |
| 🧑‍💼 Взрослые | Все нейросети, рабочие сценарии |
| 🧓 60+ | Крупный шрифт, медленная озвучка, защита от мошенников и дипфейков |

## Как устроено

- **Путь обучения**: 4 базовых урока (Что такое ИИ, Безопасность, Искусство промпта, Проверяй ИИ) и урок по каждой нейросети — карточки + тест.
- **Игры**: «Промпт-конструктор», «Подбери ИИ», «Детектор выдумок», «Вызов дня» (двойной XP).
- **Геймификация**: XP, 11 уровней, 15 значков, серия дней, звёзды за уроки.
- **Озвучка** 🔊 карточек и вопросов (русский голос браузера).
- **Новое**: лента обновлений нейросетей. За чтение +5 XP, за вопрос по новости +10 XP.
- Работает офлайн, прогресс хранится на устройстве.

## Как добавлять обновления

**Для всех пользователей** — добавь запись в `updates.json` и запушь в `main`:

```json
{
  "id": "2026-10-01-chatgpt-something",
  "date": "2026-10-01",
  "tool": "chatgpt",
  "title": "Короткий заголовок",
  "text": "Что изменилось и как этим пользоваться.",
  "kid": "Необязательно: объяснение для детей.",
  "link": "https://…",
  "q": { "q": "Вопрос-проверка?", "a": ["Правильный", "Неправильный", "Неправильный"], "c": 0 }
}
```

`tool` — id нейросети: `chatgpt`, `claude`, `gemini`, `copilot`, `perplexity`, `deepseek`, `gigachat`, `alice`,
`midjourney`, `suno`, `github-copilot`. Для прочих укажи `"tool": "other", "toolName": "Название"`.

Новую нейросеть (с уроком) можно добавить в массив `tools` того же файла — поля как в `data.js`
(`id`, `name`, `maker`, `emoji`, `cat`, `url`, `about`, `start`, `can`, `tips`, `prompt`, `care`, `quiz`, `ages`).

**Прямо в приложении** — вкладка «Новое» → «＋ Добавить» (новость) или «Нейросети» → «＋ Добавить новую нейросеть».
Они сохраняются на устройстве; кнопка «Экспорт» выгружает их в JSON, который можно вставить в `updates.json`.

## Файлы

- `index.html` — приложение (без зависимостей)
- `data.js` — уроки, тесты и игры
- `updates.json` — лента обновлений и дополнительные нейросети
- `sw.js`, `manifest.webmanifest`, `icons/` — офлайн-режим и установка на телефон
