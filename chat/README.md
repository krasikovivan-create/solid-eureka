# 💬 Связь — чат онлайн и офлайн

Веб-мессенджер на React + TypeScript, который работает и без интернета: сообщения, фото и видео
сохраняются на устройстве и отправляются сами, как только появляется связь.

Два режима живут рядом:
- **настоящий** — подключаешь свой номер к серверу (`chat/server`), находишь друзей по номеру или из контактов телефона, переписываешься и созваниваешься по видео с реальными людьми;
- **демо** — встроенные демо-контакты и «сервер» в браузере, чтобы всё посмотреть без регистрации (их можно скрыть в меню ⋮).

Адрес после публикации: `https://<пользователь>.github.io/solid-eureka/chat/`

## Возможности

- **Список чатов** с аватарами, точкой «в сети», последним сообщением, временем, счётчиком непрочитанных, черновиками, «печатает…» и поиском.
- **Чат**: текст с временем, разделители по дням, «Новые сообщения», группировка пузырей, кнопка «вниз» со счётчиком новых.
- **Фото** — превью в чате (место резервируется заранее по пропорциям), полноэкранный просмотр и скачивание.
- **Видео** — встроенный плеер с длительностью и размером.
- Прикрепить можно скрепкой, перетаскиванием в окно или вставкой из буфера (Ctrl+V). Несколько файлов сразу, подпись — к первому.
- **Голосовые и кружки, как в Telegram** — кнопка справа от поля ввода (когда поле пустое):
  - *нажать* — переключить 🎤 голосовое ↔ ⭕ кружок (видеосообщение);
  - *удерживать* — запись, *отпустить* — отправить; *провести влево* — отменить; *провести вверх* — закрепить запись без рук, потом отправить кнопкой или удалить корзиной;
  - голосовое: плеер с волной громкости, перемотка по волне, скорость 1× / 1,5× / 2×;
  - кружок: до 60 секунд с фронтальной камеры, в чате крутится без звука, по нажатию играет со звуком и кольцом прогресса;
  - записывать можно и без интернета — запись ляжет в очередь, как фото.
: 🕓 ждёт отправки → ✓ отправлено → ✓✓ доставлено → синие ✓✓ прочитано. Нажми на своё сообщение, чтобы увидеть точное время отправки, доставки и прочтения.
- **Статус контакта**: «в сети», «был(а) в сети 5 мин назад», «печатает…».

### Мой номер и настоящие друзья

- **Мой номер** (баннер вверху списка или меню ⋮): номер, имя и адрес сервера. Номер не проверяется по SMS — он закрепляется за устройством секретным ключом, и занять его с другого устройства нельзя.
- **Найти друга по номеру** — поиск среди зарегистрированных; незнакомый номер можно пригласить.
- **Контакты телефона** — какие номера из записной книжки уже в «Связи»:
  - Android (Chrome): системный выбор контактов;
  - iPhone и все остальные: файл `.vcf` (экспорт из «Контактов» iPhone, Google Контактов или Android — инструкция прямо в окне). Файл читается на устройстве, на сервер уходят только номера для сверки.
- Переписка с реальными людьми: доставлено/прочитано, «печатает…», «в сети/был в сети», фото и видео, группы. Если собеседник офлайн — сервер хранит сообщение и отдаёт, когда он подключится; если офлайн ты — сообщения ждут в очереди на устройстве.
- **Настоящие аудио- и видеозвонки** (WebRTC, зашифрованы): 1:1 и групповые (каждый с каждым, удобно до 4–5 человек), «занято», «отклонён», «абонент не в сети», выключение камеры/микрофона, смена камеры. Входящий звонок приходит, пока приложение открыто (в том числе в фоновой вкладке — с системным уведомлением, если разрешить).

### Друзья, группы, звонки (демо)

- **Добавить друга по номеру** (кнопка ✏️ или вкладка «Контакты»): вводишь номер — поле само форматирует его, «сервер» находит человека, можно подписать его своим именем и сразу написать. Если номер не зарегистрирован — кнопка «Пригласить» (системное «Поделиться» или копирование ссылки). Для демо: +7 916 123-45-67, +7 903 555-01-01, +7 926 777-88-99 или любой другой номер.
- **Новый чат** с любым контактом и **группы** из нескольких человек: название, участники, добавление новых участников в панели группы. В группе видно, кто написал (имя и аватар), кто печатает, сколько участников в сети; отвечают разные участники.
- **Аудио- и видеозвонки** — из шапки чата, из контактов, из панели профиля или кнопкой «Перезвонить» в истории:
  - используются настоящие камера и микрофон (браузер спросит разрешение); выключить микрофон, включить/выключить камеру, переключить фронтальную/основную камеру;
  - гудки, рингтон входящего, таймер разговора, «Вызов…», «Нет ответа», «Звонок отклонён»;
  - групповой звонок — сетка участников с их статусами;
  - звонок можно свернуть в плашку сверху и продолжать переписку;
  - входящие звонки приходят сами (раз в несколько минут) или сразу — через меню ⋮ → «Демо: входящий звонок»;
  - каждый звонок попадает в историю чата: исходящий/входящий/пропущенный, длительность.
- С демо-контактами собеседник в звонке имитируется (его «видео» — анимация). С реальными людьми — настоящий звонок, см. выше.

### Офлайн

- Индикатор подключения в шапке: *Онлайн* / *Офлайн · N в очереди* / *Синхронизация…*, плюс плашка в чате.
- Писать и прикреплять файлы можно без интернета — сообщение сразу появляется со статусом «ждёт отправки».
- При восстановлении связи очередь отправляется автоматически по порядку, приходит уведомление «Синхронизация завершена».
- То, что «сервер» хотел сообщить, пока связи не было (доставки, прочтения, новые сообщения), приходит после подключения.
- Приложение открывается без сети (Service Worker), в том числе после перезагрузки страницы.
- Звонки и поиск по номеру требуют связи — без неё приложение прямо об этом говорит; группу можно создать и офлайн, она «доедет» до сервера с первым сообщением.
- **Режим полёта** в меню ⋮ — проверить офлайн, не отключая Wi‑Fi. Там же **сброс демо-данных**.

## Как устроено

| Что | Где |
|---|---|
| Сообщения, контакты, чаты и группы, черновики | `localStorage` (`svyaz.state.v2`; данные первой версии переносятся автоматически) — `src/storage/local.ts` |
| Фото и видео (Blob) | IndexedDB `svyaz-media` — `src/storage/media.ts` |
| Состояние приложения | маленький стор на `useSyncExternalStore` — `src/store.ts` |
| Очередь отправки и синхронизация | `src/sync.ts` |
| Настоящий сервер: аккаунты по номеру, пересылка и очередь сообщений, «в сети», фото/видео, сигнализация звонков | `server/server.js` (Node + `ws`) |
| Подключение к серверу (WebSocket с автопереподключением, загрузка медиа) | `src/net/client.ts` |
| Реальные контакты, приём/отправка, квитанции, «печатает» | `src/real.ts` |
| WebRTC: соединения, SDP/ICE, камера без переподключения | `src/rtc.ts` |
| Чтение контактов телефона (.vcf, Contact Picker) | `src/vcard.ts` |
| Запись голосовых и кружков (MediaRecorder, волна) | `src/recorder.ts`, кнопка — `src/components/RecordControl.tsx`, плееры — `src/components/MediaNotes.tsx` |
| Mock-сервер для демо-контактов | `src/mock/server.ts` |
| Звонки: камера/микрофон, состояния вызова, история | `src/calls.ts`, экран — `src/components/CallScreen.tsx` |
| Звуки звонка (Web Audio, без файлов) | `src/tones.ts` |
| Демо-данные | `src/mock/seed.ts` |
| Service Worker | `src/sw.template.js` → при сборке `dist/sw.js` со списком файлов и версией |

Жизненный цикл сообщения: оно сохраняется локально со статусом `pending` (файл — сразу в IndexedDB),
затем очередь отправляет его «серверу» → `sent`. Если контакт в сети, сервер сообщает `delivered`,
через пару секунд `read`, и контакт может ответить. Если связь пропала посреди отправки, неотправленное
остаётся в очереди и уходит при следующем подключении.

## Сервер: как запустить

Сервер — один файл `server/server.js` (Node 20+, единственная зависимость `ws`). Он не хранит переписку:
доставил сообщение — забыл; история живёт на устройствах. Хранит только аккаунты и ещё не доставленное.

**Бесплатно на Render (≈5 минут):**
1. Зайдите на [render.com](https://render.com) через GitHub.
2. **New → Blueprint** → выберите этот репозиторий → **Apply**. Render прочитает `render.yaml` из корня и создаст сервис `svyaz-server`.
3. Скопируйте адрес сервиса, например `https://svyaz-server.onrender.com` (проверка: `/health` отвечает `{"ok":true…}`).
4. Укажите адрес в приложении одним из способов:
   - в репозитории GitHub: **Settings → Secrets and variables → Actions → Variables → New variable** `CHAT_SERVER_URL` = адрес сервера, затем перезапустите деплой (Actions → Deploy to GitHub Pages → Run workflow) — адрес «вшьётся» в сайт для всех;
   - или просто вставьте адрес в поле «Адрес сервера» в окне «Мой номер».

Особенности бесплатного тарифа: сервис засыпает без подключений и просыпается до минуты (приложение
само переподключается); при перезапуске теряются недоставленные сообщения и загруженные файлы, а аккаунты
восстанавливаются сами при следующем входе с устройства. Для постоянного хранения подключите диск и задайте `DATA_DIR`.

**Настройки** (переменные окружения): `ALLOWED_ORIGINS` — с каких сайтов можно подключаться (в `render.yaml`
уже стоит адрес GitHub Pages); `TURN_URLS`, `TURN_USERNAME`, `TURN_CREDENTIAL` — TURN-сервер для звонков.
Без TURN звонки идут напрямую (STUN от Google) и работают в большинстве сетей; если у кого-то звонок
«соединяется» бесконечно (строгий NAT у мобильного оператора или корпоративная сеть), подключите TURN —
например, бесплатный тариф Metered или свой coturn.

**Локально:**
```bash
cd chat/server && npm install && node server.js     # ws://localhost:8080
```
и в приложении укажите адрес `http://localhost:8080`.

Зависимости: только `react` и `react-dom` (плюс Vite и TypeScript для сборки).

## Запуск

```bash
cd chat
npm install
npm run dev       # разработка, http://localhost:5173 (Service Worker в dev не регистрируется)
npm run build     # проверка типов и сборка в dist/
npm run preview   # собранная версия с Service Worker, http://localhost:4173
```

На GitHub Pages приложение собирается workflow-ом `.github/workflows/pages.yml` и публикуется в папку `chat/`.

## Установка на телефон

**iPhone:** Safari → «Поделиться» → «На экран „Домой“». **Android:** Chrome → ⋮ → «Установить приложение».
