# 🤖 Виртуальный сотрудник в Telegram

ИИ-ассистент для компании, которая внедряет ИИ в бизнес клиентов. Работает в Telegram,
понимает обычный язык и сам решает, что сделать: поставить задачу, напомнить, записать
клиента, провести аудит, подготовить коммерческое предложение, найти ответ в документах
или написать текст в стиле компании.

**Как запустить** — пошагово, только с телефона: [SETUP.md](SETUP.md).
**Почему сделано именно так** — [DECISIONS.md](DECISIONS.md).

## Что умеет

| | Функция | Как пользоваться |
|---|---|---|
| 👋 | **Знакомство** | При первом `/start` бот спрашивает название и описание компании, своё имя, должность и стиль общения. Изменить — `/settings` |
| 💬 | **Свободный диалог** | Пишете как человеку — агент сам выбирает нужный инструмент (27 инструментов). Команды — запасной путь |
| 📋 | **Задачи** | Из обычной фразы: приоритеты, сроки, статусы, список, правка, удаление |
| ⏰ | **Напоминания** | Точно по времени, с кнопками «Сделано / +15 мин / +1 час / Завтра». Хранятся в БД и восстанавливаются после перезапуска; пропущенные за время простоя приходят сразу |
| ☀️🌙 | **План дня и итоги** | Каждый день в 9:00 — план (сегодняшние, просроченные, важные), в 19:00 — итоги (выполнено, работа с клиентами, что завтра). Время и включение — в `/settings` |
| 👥 | **Клиенты и лиды** | Карточка (компания, сфера, контакты, статус сделки, заметки), история взаимодействий, follow-up-напоминания, воронка по статусам |
| 🔍 | **Аудит процессов** | Интервью из 10 вопросов (состояние хранится в БД — можно прерваться и продолжить), затем отчёт: карта рутинных процессов, что автоматизировать ИИ, сложность, сроки, экономия часов в месяц |
| 📄 | **Коммерческое предложение** | По итогам аудита: проблема → решение → этапы → сроки → стоимость. Присылает готовый DOCX. Стоимость = часы × ставка из `/settings` |
| 📚 | **База знаний** | Отправьте PDF, DOCX или TXT — бот сохранит и проиндексирует (BM25, без внешних сервисов) и будет отвечать со ссылкой на документ. Список и удаление — `/kb` |
| ✍️ | **Тексты** | Письма клиентам, посты, отчёты, сообщения — в стиле компании, с учётом карточки клиента и фактов из памяти |
| 🧠 | **Память** | Последние 20 сообщений дословно + краткое резюме более старых; важные факты о компании и клиентах |
| 💰 | **Контроль расходов** | Лимит токенов на запрос, учёт стоимости каждого запроса, `/usage` — расходы за день и месяц, дневной/месячный бюджет |
| 🔒 | **Доступ** | Только для `ALLOWED_USER_IDS`; если список пуст — владельцем становится первый, кто нажал `/start` |

## Примеры фраз

**Задачи и напоминания**
- «Напомни завтра в 10 позвонить Иванову»
- «Добавь задачу подготовить отчёт до пятницы, приоритет высокий»
- «Что у меня на сегодня?» · «Покажи просроченные» · «Что на неделе?»
- «Перенеси задачу 5 на понедельник 12:00» · «Задача 3 готова» · «Удали задачу 7»

**Клиенты**
- «Добавь клиента ООО Ромашка, ритейл, контакт Пётр Сидоров, +7 900 000-00-00»
- «Созвонился с Ромашкой: интересуются ботом для поддержки, ждут КП»
- «Переведи Ромашку в переговоры» · «Покажи воронку» · «Что у нас по Ромашке?»
- «Напомни написать Ромашке через 3 дня»

**Аудит и КП**
- «Проведи аудит процессов для Ромашки» — бот задаст 10 вопросов по очереди
- «Сделай КП по аудиту 1» — пришлёт DOCX-файл

**База знаний** (сначала отправьте файл)
- «Какие у нас условия оплаты?» · «Что в договоре сказано про сроки?»

**Тексты**
- «Напиши письмо Ромашке: спасибо за встречу, КП во вложении»
- «Пост для телеграм-канала: как ИИ экономит 20 часов в месяц отделу продаж»
- «Сделай отчёт за неделю по клиентам и задачам»

**Память и настройки**
- «Запомни: наша ставка 3500 ₽ в час, предоплата 50%»
- «Что ты помнишь о Ромашке?» · «Забудь факт 4»
- «Присылай утренний план в 8:30» · «Сколько я потратил на ИИ?»

## Команды

| Команда | Что делает |
|---|---|
| `/start` | Знакомство или приветствие с главным меню |
| `/menu` | Главное меню с кнопками |
| `/today` | План на сегодня |
| `/tasks` | Открытые задачи с кнопками «выполнено» и «удалить» |
| `/clients` | Клиенты и карточки, смена статуса, аудит |
| `/audit` | Аудит процессов, готовые отчёты и КП |
| `/kb` | Документы в базе знаний |
| `/settings` | Профиль компании, время сводок, часовой пояс, ставка |
| `/usage` | Расходы на ИИ за день и месяц |
| `/new` | Начать диалог заново (факты, задачи, клиенты сохраняются) |
| `/cancel` | Отменить текущее действие или аудит |
| `/help` | Справка с примерами |

## Как обновлять

Railway пересобирает и перезапускает бота при каждом изменении в ветке `main`.

1. Изменения вносятся через pull request (например, попросите Claude Code в облачной
   сессии: «добавь в бота …»), он проверяется тестами в GitHub Actions
   (`.github/workflows/ai-employee.yml`).
2. Вы открываете PR в приложении GitHub или в браузере → **Merge pull request**.
3. Через 2–3 минуты Railway выкатит новую версию. Данные (база, документы, КП) лежат
   на Volume `/data` и не теряются.

Откатиться: Railway → сервис → **Deployments** → ⋮ у предыдущего деплоя → **Redeploy**.

## Копия агента с другой ролью для клиента

Один и тот же код можно запустить сколько угодно раз — у каждой копии своя база,
свой бот и свои настройки.

**Быстро (без изменения кода)** — например, «менеджер по продажам» для клиента:
1. У @BotFather создайте нового бота (`/newbot`) → новый токен.
2. В Railway в том же или новом проекте: **+ New** → **GitHub Repo** → `solid-eureka`.
   Повторите шаги 5.1–8 из [SETUP.md](SETUP.md): Root Directory `ai-employee`,
   свой Volume `/data`, свои переменные (новый токен, ID клиента в `ALLOWED_USER_IDS`,
   можно отдельный ключ Anthropic, чтобы расходы шли на клиента).
3. Клиент нажимает `/start` и при знакомстве задаёт свою компанию, имя, должность и стиль
   сотрудника. Всё остальное (задачи, клиенты, база знаний, тексты) работает сразу.

**Глубже (своя роль и сценарии)** — сделайте форк репозитория (GitHub → **Fork**),
подключите форк к Railway и поменяйте:
- `app/agent/prompts.py` → `STATIC_SYSTEM` — описание роли и правила поведения агента;
- `app/services/audit.py` → `AUDIT_QUESTIONS` — вопросы интервью
  (например, для HR-аудита или аудита продаж);
- `app/services/proposals.py` → структура КП и оформление DOCX;
- `app/texts.py` → тексты приветствия и справки;
- `app/tools/` → новые инструменты: функция с декоратором `@registry.register(...)`
  сразу становится доступна агенту.

## Устройство

```
ai-employee/
├── app/
│   ├── __main__.py      # запуск: health-check, планировщик, polling
│   ├── bot.py           # сборка диспетчера, обработка ошибок, /health
│   ├── config.py        # переменные окружения, цены моделей
│   ├── context.py       # общий контекст (БД, ИИ, база знаний, планировщик)
│   ├── database/        # модели SQLAlchemy (async SQLite) и подключение
│   ├── services/        # бизнес-логика: задачи, клиенты, аудит, КП, документы, BM25, расходы
│   ├── agent/           # Claude: обёртка с лимитами и учётом, цикл tool use, промпты
│   ├── tools/           # инструменты агента (27 шт.)
│   ├── handlers/        # Telegram: онбординг, меню, настройки, аудит, документы, чат
│   └── scheduler/       # APScheduler: напоминания и ежедневные сводки
├── tests/               # pytest: 100+ тестов, Telegram и Anthropic замоканы
├── Dockerfile, railway.json, .env.example
└── SETUP.md, README.md, DECISIONS.md
```

## Для разработчика

```bash
cd ai-employee
pip install -r requirements-dev.txt
cp .env.example .env        # заполните токены; DB_PATH=data/bot.db для локального запуска
python -m app               # запуск
pytest -q                   # тесты
ruff check . && ruff format --check .
```
