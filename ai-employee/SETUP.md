# Запуск виртуального сотрудника — только с телефона

Займёт 20–30 минут. Понадобятся: телефон с Telegram, браузер (Safari или Chrome),
аккаунт GitHub (этот репозиторий) и банковская карта для оплаты Claude API и Railway.

> Совет: открывайте сайты в браузере, а не в приложениях — так видно все настройки.
> Если интерфейс показывает урезанную мобильную версию, в Safari нажмите «аА» →
> «Запрос настольного веб-сайта», в Chrome — ⋮ → «Версия для ПК».

Ниже по шагам; в конце каждого шага написано, что нужно сохранить. Заведите заметку
в телефоне и складывайте туда: **токен бота**, **ваш Telegram ID**, **ключ Anthropic**.

---

## Шаг 1. Влейте код в ветку main

Railway разворачивает бота из ветки `main`.

1. Откройте в браузере `github.com` → войдите → репозиторий **solid-eureka**.
2. Вкладка **Pull requests** → откройте PR «Виртуальный сотрудник…».
3. Пролистайте вниз → зелёная кнопка **Merge pull request** → **Confirm merge**.

Готово, код в `main`.

---

## Шаг 2. Создайте бота у @BotFather и получите токен

1. В Telegram найдите **@BotFather** (с синей галочкой) → **Запустить / Start**.
2. Отправьте `/newbot`.
3. Введите имя бота, которое увидят люди, например: `Анна — ассистент`.
4. Введите username — латиницей и обязательно с окончанием `bot`, например `my_company_ai_bot`.
5. BotFather пришлёт сообщение с токеном вида `1234567890:AAE...`.
   Нажмите на токен — он скопируется.

📌 Сохраните в заметку: **токен бота**. Никому его не показывайте.

---

## Шаг 3. Узнайте свой Telegram ID

1. В Telegram найдите **@userinfobot** → **Start**.
2. Бот ответит сообщением, где есть строка `Id: 123456789`.

📌 Сохраните: **ваш Telegram ID** (только цифры).

Если хотите дать доступ коллегам — пусть каждый сделает то же самое и пришлёт вам свой ID.

---

## Шаг 4. Получите ключ Claude API (Anthropic)

1. Откройте в браузере `console.anthropic.com` → **Sign up** (или **Log in**).
   Подтвердите почту.
2. Пополните баланс: меню (☰ слева вверху) → **Settings** → **Billing** →
   **Buy credits** / **Add funds**. Для старта достаточно $5–10.
3. Создайте ключ: меню → **API Keys** → **Create Key** → имя `telegram-bot` →
   **Create** → нажмите **Copy**.
   Ключ показывается один раз и начинается с `sk-ant-`.
4. (Рекомендуется) Там же в **Settings → Limits** можно задать месячный лимит трат.

📌 Сохраните: **ключ Anthropic**.

---

## Шаг 5. Создайте проект на Railway из GitHub

1. Откройте `railway.com` → **Login** → **Continue with GitHub** → разрешите доступ.
   (Нужен тариф Hobby, $5 в месяц: **Account → Plans**. На бесплатном пробном
   периоде тоже можно начать.)
2. Нажмите **New Project** (или **+ New**) → **Deploy from GitHub repo**.
3. Если репозитория нет в списке: **Configure GitHub App** → выберите свой аккаунт →
   **Only select repositories** → отметьте **solid-eureka** → **Save** → вернитесь в Railway.
4. Выберите **solid-eureka**. Railway создаст сервис и попробует его собрать —
   первая сборка может упасть, это нормально: настройки ещё не заданы.

### 5.1. Укажите папку бота

1. Нажмите на карточку сервиса → вкладка **Settings**.
2. Раздел **Source** → **Root Directory** → **Add Root Directory** → впишите
   `ai-employee` → галочка ✓.
3. Убедитесь, что **Branch** = `main` (автодеплой при каждом изменении в main).
4. Раздел **Config-as-code** (или **Railway Config File**) → **Add File Path** →
   впишите `/ai-employee/railway.json` → ✓.
   Из этого файла Railway возьмёт сборку через Dockerfile, команду запуска
   `python -m app`, health-check `/health` и автоперезапуск при сбое.

---

## Шаг 6. Добавьте Volume (диск для базы данных)

Без Volume база данных стиралась бы при каждом обновлении бота.

1. Вернитесь на схему проекта (стрелка «назад» или название проекта сверху).
2. Нажмите **+ Create** (или **+ New**) → **Volume**.
   Другой способ: долгое нажатие (правый клик) на карточке сервиса → **Attach Volume**.
3. Выберите ваш сервис (**solid-eureka**).
4. **Mount path**: впишите `/data` → **Create** / ✓.

На схеме под сервисом появится значок диска.

---

## Шаг 7. Добавьте переменные окружения

1. Нажмите на карточку сервиса → вкладка **Variables**.
2. Нажмите **Raw Editor** (удобнее всего с телефона) и вставьте, подставив свои значения:

```
TELEGRAM_BOT_TOKEN=1234567890:AAE...ваш_токен
ANTHROPIC_API_KEY=sk-ant-...ваш_ключ
ALLOWED_USER_IDS=123456789
DB_PATH=/data/bot.db
MODEL_SMART=claude-sonnet-5-5
MODEL_FAST=claude-haiku-4-5
```

3. Нажмите **Update Variables** (или **Save**).

Пояснения:
- `ALLOWED_USER_IDS` — ваш ID из шага 3. Несколько человек — через запятую:
  `123456789,987654321`. Если оставить пустым, владельцем станет первый, кто нажмёт
  `/start` в боте (лучше указать явно).
- По желанию добавьте лимиты расходов: `DAILY_BUDGET_USD=2` и `MONTHLY_BUDGET_USD=30`.
  Все остальные необязательные переменные описаны в файле `.env.example`.

---

## Шаг 8. Запустите деплой

1. Сверху на схеме появится плашка **Apply changes / Deploy** — нажмите **Deploy**.
   (Если плашки нет: сервис → вкладка **Deployments** → ⋮ у последнего деплоя →
   **Redeploy**.)
2. Откройте **Deployments** → последний деплой → **View logs**.
   Через 1–3 минуты должны появиться строки:
   - `Health-check слушает порт ...`
   - `Планировщик запущен ...`
   - `Бот @ваш_бот запущен`
3. Статус деплоя станет зелёным **Active / Success**.

Домен (Networking → Generate Domain) **не нужен**: бот сам забирает сообщения из Telegram.

---

## Шаг 9. Проверьте бота

1. Откройте в Telegram своего бота (ссылка `t.me/имя_бота` есть в сообщении BotFather) →
   **Запустить / Start**.
2. Бот задаст 5 вопросов: название компании, описание, имя и должность сотрудника, стиль
   общения. Ответьте — и появится главное меню.
3. Проверьте основные функции:
   - напишите `Напомни через 2 минуты проверить бота` — через 2 минуты придёт напоминание
     с кнопками «Сделано / Отложить»;
   - `Добавь клиента ООО Ромашка, ритейл, контакт Пётр` → `Покажи воронку`;
   - отправьте боту любой PDF/DOCX/TXT и спросите что-нибудь по нему;
   - `/usage` — расходы на ИИ за день и месяц.
4. Утром (по умолчанию в 9:00 МСК) придёт план дня, вечером в 19:00 — итоги.
   Время меняется в `/settings`.

Готово! 🎉

## Если что-то пошло не так

| Что видно | Что сделать |
|---|---|
| В логах `Не заданы обязательные переменные окружения` | Шаг 7: проверьте, что TELEGRAM_BOT_TOKEN и ANTHROPIC_API_KEY сохранены, затем Redeploy |
| В логах `Telegram отклонил токен` | Токен скопирован с ошибкой. В @BotFather: `/mybots` → бот → **API Token** → скопируйте заново |
| Сборка падает с `Dockerfile not found` / собирается не тот проект | Шаг 5.1: Root Directory = `ai-employee`, путь конфига = `/ai-employee/railway.json` |
| Бот пишет «У вас нет доступа» и показывает ID | Добавьте этот ID в `ALLOWED_USER_IDS` (через запятую) → Redeploy |
| Бот отвечает «Ключ Anthropic API не подходит» | Создайте новый ключ (шаг 4) и обновите ANTHROPIC_API_KEY |
| «На балансе Anthropic закончились средства» | console.anthropic.com → Settings → Billing → пополнить |
| «Модель не найдена» | Проверьте MODEL_SMART / MODEL_FAST (значения из шага 7) |
| После обновления пропали задачи и клиенты | Не подключён Volume (шаг 6) или DB_PATH не `/data/bot.db` |
| В логах `Conflict: terminated by other getUpdates request` | Бот запущен где-то ещё с тем же токеном. Оставьте один экземпляр |
| Бот молчит | Railway → Deployments → View logs: там будет причина. Сам бот при любой ошибке пишет понятное сообщение |

## Сколько это стоит

- **Railway**: тариф Hobby — $5 в месяц, этого хватает на бота с Volume.
- **Claude API**: оплата по факту. Обычный диалог идёт через быструю модель
  (≈ $0.002–0.01 за сообщение), аудит и КП — через умную (≈ $0.05–0.2 за документ).
  Точные цифры — команда `/usage`. Ограничить траты можно переменными
  `DAILY_BUDGET_USD` / `MONTHLY_BUDGET_USD` и лимитом в консоли Anthropic.
