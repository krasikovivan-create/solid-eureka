# 🤖 Бот-помощник для Telegram

Бот с меню из кнопок:

- **📝 Заметки** — сохранить текст, посмотреть список (по 8 на страницу), удалить кнопкой 🗑.
- **⏰ Напоминания** — пишешь как обычно, бот присылает сообщение в нужное время:
  `через 20 минут выключить духовку`, `в 18:30 тренировка`, `завтра в 9 позвонить врачу`,
  `в пятницу в 19:00 кино`, `05.10 в 12:00 оплатить интернет`, `позвонить маме завтра в 10`.
  Пришедшее напоминание можно отложить: «+10 мин», «+1 час», «Завтра».
- **❓ Вопросы** — ответы на частые вопросы кнопками; можно и просто спросить своими словами.
- Если бот не понял сообщение, он предложит сохранить его в заметки или сделать напоминанием.

Команды: `/menu`, `/note текст`, `/notes`, `/remind когда что`, `/reminders`, `/faq`, `/tz` (часовой пояс),
`/cancel`, `/forget` (удалить все свои данные), `/help`, `/stats` (только для админа).

Написан на чистом Node.js 22 без библиотек: весь код — в папке `src/`.

| Файл | Что внутри |
|------|------------|
| `src/index.js` | запуск: получение сообщений (long polling или webhook), таймер напоминаний |
| `src/bot.js` | всё, что бот говорит и делает: меню, заметки, напоминания, кнопки |
| `src/timeparse.js` | понимает «через 10 минут», «завтра в 9», «в пятницу в 19:00» |
| `src/faq.js` | **частые вопросы — меняй под себя** |
| `src/store.js` | хранение данных: файл `data/db.json` или Upstash Redis |
| `src/telegram.js` | маленький клиент Telegram Bot API |

## 1. Создать бота в Telegram

1. Открой [@BotFather](https://t.me/BotFather) → `/newbot`.
2. Придумай имя и адрес (должен заканчиваться на `bot`, например `ivan_helper_bot`).
3. BotFather пришлёт **токен** вида `123456789:AAH...` — это пароль от бота, никому его не показывай.

По желанию там же: `/setdescription`, `/setabouttext`, `/setuserpic` — описание и аватарка.

## 2. Запустить на своём компьютере

Нужен [Node.js 22+](https://nodejs.org).

```bash
cd telegram-bot
cp .env.example .env      # и впиши в .env свой BOT_TOKEN
npm start
```

Напиши боту в Telegram `/start` — он ответит. Пока терминал открыт, бот работает; данные лежат в `data/db.json`.

Тесты: `npm test`.

## 3. Запустить в интернете (Render), чтобы работал всегда

Бот уже добавлен в `render.yaml` в корне репозитория рядом с сервером «Связи».

1. [Render](https://dashboard.render.com) → **New → Blueprint** → выбери этот репозиторий → **Apply**
   (если Blueprint уже подключён — Render сам предложит создать новый сервис `telegram-helper-bot`).
2. Открой сервис `telegram-helper-bot` → **Environment** и заполни:
   - `BOT_TOKEN` — токен от BotFather;
   - `ADMIN_IDS` — твой Telegram id (узнать у [@userinfobot](https://t.me/userinfobot)), чтобы работал `/stats`;
   - `UPSTASH_REDIS_REST_URL` и `UPSTASH_REDIS_REST_TOKEN` — см. ниже.
3. Сохрани — сервис перезапустится. Webhook бот поставит сам (адрес сервиса Render передаёт в `RENDER_EXTERNAL_URL`).

### Где хранить данные на бесплатном Render

На бесплатном тарифе у Render нет диска: при каждом перезапуске и «засыпании» файлы стираются,
а вместе с ними заметки и напоминания. Поэтому данные нужно держать в бесплатной базе **Upstash Redis**:

1. Зарегистрируйся на [upstash.com](https://upstash.com) → **Create Database** (Redis, бесплатный план, любой регион).
2. На странице базы в разделе **REST API** скопируй `UPSTASH_REDIS_REST_URL` и `UPSTASH_REDIS_REST_TOKEN`.
3. Вставь их в Environment сервиса на Render.

Проверить, что всё подключено: напиши боту `/stats` (с аккаунта из `ADMIN_IDS`) — в строке «Хранилище» должно быть `Upstash Redis`.

### Засыпание бесплатного сервиса

Бесплатный сервис Render засыпает после 15 минут без запросов. Что это значит для бота:

- **сообщения** будят его сами — первый ответ после сна приходит секунд через 30–60, дальше быстро;
- **напоминания**, время которых пришлось на сон, придут, когда бот проснётся, с пометкой об опоздании.

Чтобы напоминания приходили точно вовремя, бот не должен засыпать. Варианты:

- бесплатный пингер, например [cron-job.org](https://cron-job.org): задание открывать
  `https://telegram-helper-bot.onrender.com/health` (свой адрес — на странице сервиса) каждые 10 минут.
  Учти: на бесплатном Render 750 часов работы в месяц на все сервисы вместе — этого хватает
  на один постоянно работающий сервис, а не на два (бот + сервер «Связи»);
- платный тариф Render (Starter) — тогда можно и диск подключить, и Upstash не нужен;
- любой свой сервер или компьютер, который всегда включён: просто `npm start`.

## Настройки (переменные окружения)

| Переменная | Что это |
|------------|---------|
| `BOT_TOKEN` | токен от @BotFather (обязательно) |
| `BOT_TZ` | часовой пояс по умолчанию, `Europe/Moscow`; каждый может поменять свой через `/tz` |
| `ADMIN_IDS` | Telegram id админов через запятую — им доступен `/stats` |
| `WEBHOOK_URL` | публичный https-адрес сервера → режим webhook (на Render не нужен, берётся сам) |
| `WEBHOOK_SECRET` | секрет, который Telegram присылает в заголовке; по умолчанию выводится из токена |
| `PORT` | порт для `/health` и webhook, по умолчанию 8080 |
| `DATA_DIR` | папка для `db.json`, по умолчанию `./data` |
| `UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN` | хранить данные в Upstash Redis вместо файла |

## Как поменять бота под себя

- **Частые вопросы** — в `src/faq.js`: вопрос (`q`) станет кнопкой, ответ (`a`) — сообщением,
  а по словам из `keywords` бот узнаёт вопрос, написанный своими словами.
- **Тексты и кнопки меню** — в `src/bot.js` (`welcome`, `help`, `BTN`).
- **Список команд** в меню Telegram — `COMMANDS` в `src/bot.js`, обновляется при запуске бота.
